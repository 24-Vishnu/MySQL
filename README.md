## Layoffs Dataset Cleaning in MySQL

In this project, I worked with a real-world layoffs dataset and performed data cleaning using MySQL. The goal was to improve data quality and prepare the dataset for further analysis.

Throughout the project, I cleaned and organized the data by identifying duplicate records, standardizing inconsistent values, handling missing information, and refining the dataset structure where needed.

**Project Stages**

1. Deduplication
2. Data Standardization
3. Missing Data Handling
4. Schema Optimization

**Tools Used**

- MySQL
- SQL

**Result**

The final dataset is cleaner, more consistent, and ready for exploratory data analysis and reporting.
